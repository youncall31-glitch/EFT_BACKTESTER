# 120세 은퇴자금 계산기

**바로 쓰기 → https://youncall31-glitch.github.io/EFT_BACKTESTER/retire120/**

오늘 물가로 적은 지출을 해마다 물가만큼 올려 계산하고, 국민연금과 계좌별 세금·건강보험료를 반영해
120세까지 바닥나지 않는 은퇴자금을 거꾸로 계산하는 웹 계산기입니다. 설치할 것 없이 브라우저에서 바로 열립니다.

## 무엇을 계산하나

- 항목별 은퇴 후 지출(항목마다 물가상승률·기간·주기를 따로), 자녀 교육·독립 자금
- 부부 국민연금(조기·연기 수령 비교), 은퇴 후 근로소득, 연금 외 수입과 건강보험료 반영 비율
- 계좌: 일반(해외상장·국내상장 ETF), 예금, ISA, 연금저축, IRP, 퇴직연금 DC·DB
  - 연도별 납입 목록(연초 납입), 은퇴 전·후 수익률 따로, DC 연봉 상승률·샐러리캡·임금피크제
  - ISA 만기 때 연금계좌 이전과 유지 중 유리한 쪽 자동 판단
- 대출: 은퇴 때 모두 갚기와 계속 나눠 갚기 중 유리한 쪽 자동 판단
- 세금·건강보험료를 가장 적게 내는 인출 순서(7가지 전략 비교)와 해마다의 인출 시나리오
  - 어느 계좌에서 얼마를 꺼내고, 세금·건보료를 낸 뒤 실수령이 얼마인지
  - 계산 근거(세율, 연금소득 분리과세 판단, 건보료 소득·재산 점수)를 펼쳐 볼 수 있음
- 국민연금 수령 시점, 은퇴 시점, 수익률·물가 변화에 따른 필요 자금 비교, 연도별 계획표 CSV 저장
- 계산 검증
  - 자동 검산 3가지: 필요자금으로는 끝까지 버티고 1% 적으면 모자라는지, 해마다 들어온 돈과 나간 돈이 맞는지, 연말 잔액이 수익률대로 이어지고 현재가치로 되돌리면 필요자금이 되는지
  - 엑셀 수식이 든 검산용 표(CSV): 엑셀이나 구글 시트로 열면 연말 잔액과 필요자금을 다시 계산해 계산기 값과 비교
  - 공식 계산기에 넣을 값: 국민연금 예상액(국민연금공단), 지역 건보료(국민건강보험공단 모의계산), 소득세·퇴직소득세(홈택스 모의계산)

## 개인정보

- 입력값은 **이 브라우저 안(localStorage)에만** 저장되고, 어떤 서버로도 보내지 않습니다.
  계산도 모두 브라우저 안에서 합니다.
- 다른 기기·브라우저에서 이어 쓰려면 ‘저장·불러오기’ 칸의 ‘설정 파일로 저장’으로 받은 파일을 그쪽에서 ‘설정 파일 불러오기’로 여세요.
- 처음 열면 보이는 숫자는 실제 사람과 관계없는 **가상의 예시 가구**입니다. ‘빈 양식으로 시작’을 누르면 지워집니다.
- 바깥으로 나가는 요청은 글꼴(Google Fonts)을 받아 오는 것뿐입니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 계산기 전체(화면·계산 엔진이 이 한 파일에 들어 있음) |
| `sw.js` | 한 번 열면 인터넷이 없어도 열리게 하는 오프라인 저장. 연결되어 있으면 항상 새 버전을 받음 |
