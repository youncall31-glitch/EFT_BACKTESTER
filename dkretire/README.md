# 120세 은퇴자금 계산기 v2

**바로 쓰기 → https://youncall31-glitch.github.io/EFT_BACKTESTER/dkretire/**

기존 계산기(`retire120/`)를 복사해 만든 새 버전입니다. 기존 계산기는 그대로 두었고, 입력값도 따로 저장됩니다.

## v2에서 새로 생긴 것

- **은퇴 전 여윳자금 계획**(입력 2번, 계좌보다 앞): 연봉(상승률·상한)·성과급(연도별)·생활비(월 금액 또는 세후 연봉의 %)·큰 지출과 목돈 수입·대출 원리금으로
  해마다 남는 돈(여윳자금)을 계산하고, 정한 순서와 한도대로 계좌에 넣습니다. 연봉·성과급·소비가 달라지면 넣는 돈도 해마다 달라집니다.
  - 세후 소득은 2026년 세율과 4대보험료율로 추정(직접 실효율 입력도 가능)
  - **삼성전자 OPI**: 실적 연도별 DS 영업이익과 OPI1 지급률을 넣으면 다음 해에 받는 OPI1(현금, 연봉과 합쳐 누진세율)과
    OPI2(세금 49.5% + 보험료 4.967%를 떼고 자사주, 1/3씩 3년에 나눠 매도)를 세후로 계산. 주가 변화는 기본 해마다 −20%(보수적)
  - **PSU**: 정한 해부터 해마다 받는 주식(기본 2028년부터 3해, 200주씩)을 오늘 주가와 주가 변화로 계산해 세후로 반영. 고과 배수도 입력 가능
  - 결과에 해마다 성과금 현금화·소비·연금·ISA 저축·일반계좌 납입 표
  - 연금저축·IRP 1인 연 1,800만원, ISA 연 2,000만원(이월)·계약당 1억원 한도와 연금계좌 세액공제 환급 반영
  - 모자라는 해는 일반계좌·예금·ISA 원금에서 꺼내고(양도세 반영), 일하는 해 금융소득 2,000만원 초과분의 추가 세금·건보료와 ISA 가입 제한 반영
- **내 포트폴리오**: 예금을 뺀 모든 계좌에 같은 연평균 수익률(CAGR). 같은 사이트의 ETF 백테스터에 저장한 포트폴리오의 CAGR을 가져올 수 있음(읽기만 함)
- **우리 집 양식**: 부부 계좌 9개(나: 연금저축·IRP·ISA·퇴직연금 DC·해외 ETF 일반계좌, 아내: 연금저축·IRP·ISA·퇴직연금 DC)가 들어 있는 빈 양식
- **어느 계좌에 넣는 게 나을까**: 같은 여윳자금으로 넣는 계좌만 바꿔(지금 순서·추천 순서·연금저축 추가 납입 없이·배우자 계좌 없이·모두 일반계좌에) 모자란 돈을 비교
- **ISA 만기 후 처리**에 ‘해지해 일반계좌로(새로 가입)’ 추가 — 여윳자금 계획을 켜면 자동 비교에 포함
- 결과 화면 ‘은퇴 전, 해마다 어느 계좌에 얼마를 넣나’ 차트와 ‘자세히’의 연도별 여윳자금 표(CSV 저장)

기존 기능(7가지 인출 전략 비교, 자동 검산 3가지, 엑셀 검산표, 공식 계산기 확인법, 간단·고급 버전, 밝은·어두운 테마)은 그대로입니다.
여윳자금 계획을 끄면 계산 결과가 기존 계산기와 같습니다(예시 가구 필요자금 약 25.1억원).

## 개인정보

- 입력값은 **이 브라우저 안(localStorage `retire120v2.v1`)에만** 저장되고, 어떤 서버로도 보내지 않습니다. 기존 계산기(`retire120.v1`)와 저장 칸이 다릅니다.
- 처음 열면 보이는 숫자와 ‘여윳자금 예시’는 실제 사람과 관계없는 **가상의 값**입니다.
- 바깥으로 나가는 요청은 글꼴(Google Fonts)을 받아 오는 것뿐입니다.
